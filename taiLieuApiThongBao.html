Hình ảnh & Mô tả 3 Màn hình
01

Danh sách ngày thông báo

Hiển thị 10 ngày thông báo khóa nước gần nhất và số lượng.

  • Ngày thông báo (DD/MM/YYYY)
  • Số lượng khách hàng
  • Quyền xem dữ liệu
🔍 Bấm vào ảnh để phóng to
02

Danh sách khách hàng

Hiển thị danh sách khách hàng thuộc ngày được chọn.

  • Bộ lọc trạng thái (Dropdown)
  • Nút cam "Kiểm nợ"
  • Khóa nước / Chụp ảnh / CSKH

  • Nút "Khóa nước" / "Trở ngại"
  • Công nợ (Kỳ nợ, Tổng tiền)
  • Mục trước / Mục tiếp

API 02
Chi tiết danh sách khách hàng
POST api/v1/dongMoNuoc/chiTietThongBaoKhoaNuoc
Màn hình: Màn 2 & Màn 3

Lấy danh sách khách hàng của ngày được chọn và đầy đủ dữ liệu phục vụ màn hình chi tiết.
Giao diện kích hoạt API 02 (Màn 2 & Màn 3) Kích hoạt khi người dùng bấm vào 1 ngày thông báo ở Màn 1. Trả về toàn bộ danh sách khách hàng theo bộ lọc dropdown và nhóm tổ (VD: Sang Sơn [300]).

{
  "ngay_thong_bao": "23/04/2026",
  "bo_loc": "TAT_CA",
  "tu_khoa": ""

API 03
Kiểm nợ
POST api/v1/dongMoNuoc/kiemNoThongBao
Màn hình: Màn 2

Đồng bộ trạng thái thanh toán mới nhất từ dữ liệu hóa đơn.
Nút bấm kích hoạt API 03 (Màn 2) Kích hoạt khi người dùng bấm vào nút màu cam [ 📑 Kiểm nợ ] ở góc trên bên phải màn hình danh sách.
Request 
{
  "ngay_thong_bao": "23/04/2026"
}
Response 
{
  "du_lieu_xu_ly": {
    "so_luong_da_thanh_toan": 15,
    "so_luong_chua_thanh_toan": 285
  },
  "ma_loi": 0,
  "dien_giai": "Kiểm nợ thành công"
}
⚠️
Lưu ý nghiệp vụ API này vẫn cần thiết dù chức năng "Tra cứu nợ" đã bị loại bỏ. API dùng để kiểm tra và đồng bộ trạng thái thanh toán mới nhất của cả danh sách, không phải để mở một màn hình "Tra cứu nợ" riêng.
API 04
Cập nhật xử lý
POST api/v1/dongMoNuoc/capNhatThongBaoKhoaNuoc
Màn hình: Màn 2 & Màn 3

Lưu kết quả xử lý khóa nước, trở ngại, chụp ảnh và CSKH.
Giao diện kích hoạt API 04 (Màn 2 & Màn 3) Kích hoạt khi chụp ảnh hiện trường, bấm nút đỏ [ 🔒 Khóa nước ], nút vàng [ ⚠️ Trở ngại ], hoặc tích chọn ô CSKH: [✓].
Request 
{
  "id_dong_mo_nuoc": "4f92e195947698bdadb5b3d59fde3b99",
  "danh_bo": "01202015540",
  "hanh_dong": "KHOA_NUOC",
  "cskh": true,
  "hinh_anh": "data:image/jpeg;base64,...",
  "ghi_chu_tro_ngai": ""
}
Giá trị hành động (hanh_dong)
Hành động Chức năng Màn hình
KHOA_NUOC Bấm nút đỏ Khóa nước Màn 2 & Màn 3
TRO_NGAI Bấm nút vàng Ghi nhận trở ngại Màn 2 & Màn 3
CHUP_ANH Bấm icon Camera để chụp ảnh bằng chứng thông báo Màn 2 & Màn 3
UPDATE_CSKH Tích chọn hoặc bỏ chọn ô CSKH Màn 2 & Màn 3
Response 
{
  "ma_loi": 0,
  "dien_giai": "Cập nhật thành công"
}
Ghi chú nghiệp vụ
!
Đã loại bỏ chức năng "Tra cứu nợ" Theo thiết kế mới (đã đánh dấu trên ảnh chụp thực tế), liên kết "Tra cứu nợ" trên Màn 3 không còn được sử dụng.
Các thông tin nghiệp vụ liên quan đến công nợ vẫn được hiển thị trực tiếp và đầy đủ trong thông tin khách hàng, bao gồm:

• Tổng kỳ nợ (VD: 2 kỳ)
• Tổng tiền (VD: 2.349.540 VNĐ)
• Kỳ / năm (VD: 03/2026, 04/2026)
• Ngày gửi thông báo & Người thực hiện (VD: 22/04/2026 14:47 - Nguyễn Minh Sang)

Không cần tạo thêm API riêng chỉ để mở chức năng "Tra cứu nợ".
